Audio Encryption System

Python · cryptography · tinyec · wave · secrets

The problem

Securely encrypt audio data while exploring how symmetric encryption and elliptic-curve key exchange can work together in a single cryptographic system.

What I built

A hybrid encryption system combining AES-256-CFB for audio data with ECDH using the brainpoolP256r1 elliptic curve for key establishment. Each encryption session generates an ephemeral ECC key pair and derives a shared secret that is used to protect the AES key.

Security design

  • Confidentiality — AES-256-CFB encrypts the audio data.
  • Key establishment — ECDH on brainpoolP256r1 derives shared-secret material for protecting the AES key.
  • Ephemeral keys — a fresh ECC key pair is generated for each encryption session.
  • Lossless recovery — decrypted output is validated against the original WAV file.

Result & what I'd improve

The decrypted output was bit-for-bit identical to the original WAV file, validating correct and lossless recovery through the encryption and decryption pipeline. The implementation is a learning-focused demonstration rather than a production cryptosystem. Key protection currently uses XOR rather than a dedicated KDF such as HKDF, AES-CFB does not provide authenticated encryption, and private-key storage is simplified for demonstration purposes.

Secure Network Design & Implementation

Cisco Packet Tracer · Wireshark

The problem

Flat networks let a single compromised host reach everything else. The goal was to model how segmentation and access control actually reduce that blast radius in a realistic multi-department setup.

What I built

A simulated enterprise network using VLAN-based segmentation to isolate departments, with router-on-a-stick inter-VLAN routing and ACL-based least-privilege rules controlling exactly which traffic could cross between segments.

Validation

Used Wireshark packet captures to confirm the configuration behaved as intended and to identify traffic that violated the intended access policy — the same kind of check a network security review would run.

What this demonstrates

A working sense of how network architecture decisions — where you draw segment boundaries, what an ACL actually permits — directly affect how far an attacker can move laterally once they're in.
